

## Developer notes for MTB-API

# alias' setup for development
# (mtb-server) -- starts the MTB-API application in watch mode, listens for code updates on file save
# (mtb-prod-server) -- starts the MTB-API application 



## Installation

```bash
$ npm install
```

## Running the app

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Test

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
